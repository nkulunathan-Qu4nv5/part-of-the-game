# Part of the Game

![Cover Image](screenshots/Capture%20d'écran%202026-05-17%20003118.png)

### Project Overview
Part of the Game is an AI-powered application designed to transform football match results and key moments into personalized, shareable fan content. Instead of formal reports that sound like press releases, this tool allows users to select their preferred style and energy level to instantly generate content that captures the authentic voice of a true supporter. This application was built on the AWS PartyRock platform, incorporating the dynamic energy of the Adidas brand.

![UI Screenshot](screenshots/Capture%20d'écran%202026-05-17%20003105.png)

### The "Why" Behind This Project
I built this tool to bridge the gap between raw match data and impactful professional storytelling. The goal was to empower fans to quickly turn their match-day experiences into engaging content without spending hours on drafting. By automating the creative process while maintaining a human and passionate tone, this solution keeps users focused on the love of the game and their community, rather than the constraints of digital content creation.

![Configuration and Prompts](screenshots/Capture%20d'écran%202026-05-17%20003053.png)

### Key Features
The application utilizes an intuitive architecture that captures the essence of a match in just a few clicks. It automatically adjusts the tone, length, and format of the output based on the user's selected style.

![App Details](screenshots/Capture%20d'écran%202026-05-17%20003039.png)

### User Experience
The interface is designed to be lightweight and fast, eliminating the "blank page" syndrome. It guides users through a quick reflection on the match highlights to ensure the final output is punchy, relevant, and authentic.
